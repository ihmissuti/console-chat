ConsoleChat.io

The Underground Meeting Room for Developers

🚀 Quick Start

1. Open Developer Console
Press F12 or Cmd+Option+J (Mac) / Ctrl+Shift+J (Windows)
2. Start the chat: cc.start()
3. Set your username: cc.username("YourName")
4. Say hello: cc.say("Hello, world!")

Type cc.help() for all available commands
